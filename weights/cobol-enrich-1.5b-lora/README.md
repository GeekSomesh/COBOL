# cobol-enrich-1.5b (LoRA adapter)

A LoRA adapter for [Qwen/Qwen2.5-Coder-1.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-Coder-1.5B-Instruct). It writes the documentation half of a COBOL decision rule: a title, a one-sentence intent, business names for COBOL fields, and concept tags. It never produces logic. In the pipeline, operators, values, actions and source lines always come from the parser (`src/llm/enrich.py: merge`).

| | |
|---|---|
| Base model | Qwen2.5-Coder-1.5B-Instruct (Apache-2.0) |
| Adapter | LoRA r=16, alpha=32, dropout 0.05, all attention and MLP projections (18.5M trainable parameters) |
| Training data | `data/finetune/train.jsonl`: 546 rules from 200 synthetic programs, 12 templates, train split only |
| Training | 2 epochs, lr 2e-4 cosine, effective batch 8, bf16, loss on the answer only; 29 minutes on an RTX 3050 6 GB laptop GPU (`train_log.json`) |
| Prompt | `src/llm/prompts.py`, prompt version p2, zero-shot |
| Licence | Apache-2.0 (base model licence); training data is synthetic and generated by this repository |
| Checksum | `adapter_model.safetensors.sha256` |

## Results (from `results/`, synthetic held-out templates)
| Split | Model | Field names (exact) | Intent similarity |
|---|---|---|---|
| Validation (3 unseen templates) | this adapter | 0.607 | 0.795 |
| Validation | same base, 3-shot prompt | 0.476 | 0.786 |
| Test (3 other unseen templates) | this adapter (full pipeline) | 0.542 | 0.820 |
| Test | same base, 3-shot prompt | 0.566 | 0.835 |
| Test | Qwen2.5-Coder-7B, 3-shot prompt | 0.632 | 0.856 |

The adapter was selected on validation, where it won. **On the test templates it is slightly worse than prompting.** Training loss fell near zero while validation loss rose: the model learned the style of its 12 training templates. Some intents cite a number that is not in the code (4.5% on validation, 11 of 151 on test); the pipeline routes those rules to review. Use it as the fast option, not the most accurate one. See `docs/limitations.md` and `results/ERROR_ANALYSIS.md`.

## Use
```bash
.venv-train/Scripts/python scripts/merge_adapter.py   # base + adapter -> models/cobol-enrich-1.5b/merged
python scripts/serve_model.py                         # GGUF Q8_0 -> Ollama model cobol-enrich:1.5b
COBOL_LLM_MODEL=cobol-enrich:1.5b python -m uvicorn src.api.main:app --port 8000
```
With Hugging Face PEFT directly: `PeftModel.from_pretrained(AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-Coder-1.5B-Instruct"), "weights/cobol-enrich-1.5b-lora")`.
